# Mentor Behavior Type Indicator

A prototype web application that gives youth mentors a profile of their emotion management style: how they tend to respond when a mentee is upset or frustrated. Six scenarios, four profiles (The Coach, The Builder, The Cheerleader, The Fixer), practical suggestions for each.

Developed by Yunqi He, Youth Empowerment in Schools and Systems (YESS) Lab, University of South Carolina, from the Mentoring Moments Study.

Live: https://uscyesslab.github.io/mentor-style-profile/

The app stores nothing about the user. It records only anonymous completion counts.
